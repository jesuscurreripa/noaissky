# No AI' Sky

**Play:** https://noaissky.vercel.app

## EN

A small experiment with one question behind it: can an AI like GPT Astra, or whatever comes next, build a complete *No Man's Sky*-style game that runs in the browser?

This is what came out after a few hours of playing around with GPT Astra on the "medium" setting. Seed-based procedural universes, flight, atmospheric landing, on-foot exploration, scanning and optional combat. Built with Three.js and Vite, no servers or external services.

It is not a finished game. It is a snapshot of how far the tools got in an afternoon.

```sh
npm install
npm run dev
```

## ES

Un experimento pequeño con una pregunta detrás: ¿puede una IA como GPT Astra, o las que vengan después, construir un videojuego completo tipo *No Man's Sky* que corra en el navegador?

Esto es lo que salió tras unas horas jugando con GPT Astra en modo "medio". Universos procedurales por semilla, vuelo, aterrizaje atmosférico, exploración a pie, escaneo y combate opcional. Hecho con Three.js y Vite, sin servidores ni servicios externos.

No es un juego terminado. Es una foto de hasta dónde llegaron las herramientas en una tarde.
