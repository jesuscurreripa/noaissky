# No AI' Sky

**Jugar / Play:** https://noaissky.vercel.app

## ES

Un experimento. La pregunta es simple: ¿puede una IA como GPT Astra, o las que vengan después, construir un videojuego completo tipo *No Man's Sky* que corra en el navegador?

Esto es lo que salió. Universos procedurales por semilla, vuelo, aterrizaje, exploración a pie, escaneo y combate. Three.js y Vite, sin servidores ni servicios externos.

```sh
npm install
npm run dev
```

## EN

An experiment. The question is simple: can an AI like GPT Astra, or whatever comes next, build a complete *No Man's Sky*-style game that runs in the browser?

This is what came out. Seed-based procedural universes, flight, landing, on-foot exploration, scanning and combat. Three.js and Vite, no servers or external services.
